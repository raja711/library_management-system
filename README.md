# Library Management System

A comprehensive web-based Library Management System built using **Django** and styled for seamless user experience. This application helps manage books, track records, and handle user accounts efficiently from a centralized dashboard.

## Live Demo
- **Live Website:** [library-management-system-p3ov.onrender.com](https://library-management-system-p3ov.onrender.com)

## Tech Stack
- **Backend:** Python, Django
- **Frontend:** HTML5, CSS3, Templates
- **Database:** SQLite
- **Deployment:** Render, Gunicorn, WhiteNoise

## Features
- **Book Management:** Add, update, and view library records seamlessly.
- **User Accounts:** Secure user registration and signup functionality.
- **Responsive Dashboard:** Clean UI cards for fast navigation across different catalog sections.
